# Development roadmap

- [x] M0 — Product boundary, private-repo starter, core money/ledger/goal math, tests and CI.
- [x] M1 — Expo SDK 58 mobile shell, five-tab navigation, empty states, locked dependencies and device smoke test. **Prototype only; no real financial data.**
- [ ] M2 — Native local persistence, migrations, encrypted storage, recovery and backup; verify native encryption.
- [ ] M3 — Full accounts and transaction capture; transfers, card payments, EMI interest/principal and reconciliation.
- [ ] M4 — Holdings/market valuation, statement imports and duplicate detection with source provenance.
- [ ] M5 — Goals, cash flow, budgets, SIP schedules, tuition/travel plans and forecasts.
- [ ] M6 — Polish accessibility, offline UX, export/restore tests, automated checks and installable iPhone build.
- [ ] M7 — Optional authorized read-only integrations and optional encrypted multi-device sync.

Every milestone needs acceptance criteria, tests, an on-device smoke test and a reviewed PR. M1 physical iPhone launch and five-tab navigation were confirmed by the developer; large-font accessibility remains a follow-up.
